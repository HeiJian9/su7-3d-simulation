# 0.8.2 · 迎宾字标与矩阵薄雾

2026-10-30。用户指出白底 mi 像贴纸、空气中的实心长条不符合灯光投射。本轮直接替换这两处表现，不调整既有内饰灯带或基础车模。

## 当前设计

- 四门踏板外侧采用正向浅色 mi 光字，不再使用白色圆角底板。字间及周围保留地面，弱圆形柔光收敛边界，色温保持中性偏冷；门底可见灯口与遮挡散射继续随真实门运动。
- 删除悬空矩形 billboard 渲染器。空气使用有深度遮挡的体积积分，八组来源逐帧读取实际矩阵 LED 的实例变换，而不是凭场景大概位置绘制亮条。每组对应原灯腔中的一个矩阵模组，96 个 LED 仍可独立扫描。
- 空气采样经过高斯软化的动态图案，低密度缓慢变化；地面继续由两个实际 SpotLight 的 gobo 投射等宽长矩形，边缘比雾光清晰。两者共用动画时间、位置和亮度，关闭散射后地面图案保留。
- 地面 gobo 提升至 1024²；投射接收层加入深度偏移，修复原地面与投射层过近、部分视角出现闪烁或光纹消失的问题。
- 持续开关、0–100% 亮度、相对调节、查询、语音、LLM 和遥控仍走原统一状态与执行确认。不自动切换相机；解锁自动迎宾仍为有限时长。

这是实时展示近似：每模组使用一个代表性 LED 源作体积积分，地面使用两路投影，不是 96 路物理路径追踪。薄雾受“丁达尔光束／空气散射”开关及强度控制，低强度时应比地面光纹克制。

## 验证与限制

最终自动结果见 [summary.json](validation/welcome-optical/summary.json) 和 [浏览器结果](validation/welcome-optical/browser-final.json)。两种窗口为 1920×1080、1366×768；使用实际 GLB、WebGL 与本机 HTTP/SSE。

类型检查、规范检查、114 项单元、18 项双分辨率浏览器、资产与保密检查、生产构建通过。另以本机 Edge／1920×1080 连续开启 60 秒，每两秒记录真实帧率，前十秒预热后中位 79 FPS、最低 75 FPS；八组矩阵雾光持续，关闭后停止，无浏览器错误，见 [performance.json](validation/welcome-optical/performance.json)。这是本机一分钟观测，不代表其它设备或更长时段稳定性。

新增检查包含：没有悬空实体粒子、八个矩阵源位置、地面图案移动、开启前后像素变化、同一 1400 ms 动画时刻的雾光／地面独立对照、亮度归零、四门字标和灯口。原回归继续逐门比对实际地面亮像素、半开与全开落点、左右矩阵对称、近远光与双闪保护、持续开关及遥控。语音 Mock 四轮覆盖开关、40%、相对调节、工具回执、音频播放与相机保持；另有 503 故障注入，不能冒充云接口成功。

同相位图像见 [矩阵薄雾](assets/welcome-optical/matrix-mist-Edge-1920x1080.png)／[仅地面](assets/welcome-optical/ground-only-Edge-1920x1080.png)，字标见 [夜间迎宾](assets/welcome-optical/mi-entry-night-Edge-1920x1080.png)。冷启动切换体积光着色器可能需要编译，自动测试等待实际状态而非固定短等待；动作及像素断言没有放宽。

本轮没有新增真人或云接口验证。上一轮真实千问 ASR → 百炼 DeepSeek tool_calls → 实际渲染回执 → CosyVoice 的六条固定合成音源证据仍在 [0.8.1 live-speech.json](validation/welcome-correction/live-speech.json)，只作为沿用链路的历史证据，不当作本轮真人确认。用户录屏未被操作，未编造录像偏移。
