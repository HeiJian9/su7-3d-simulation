# I4 机械阶段验证

2026-10-26，当前 0.4.0。历史通过 Git 保存，未复制旧工程。真人新增语音将在 I4–I6 完整能力就绪后统一复验，本阶段不提前勾选。

四门采用原 Paint4／2／3／1 外壳、原门板、把手、后视镜及各自附件。Paint6 的跨门回边先沿 B 柱门缝切面，再分配到四门，删除原共享网格，修复预览中发现的跨门长三角尖片。前窗独立黑边随原玻璃运动并使用相同门局部裁切；车身固定窗和密封边保留。

尾箱在原 Paint5 盖板及灯条、标志等关联网格上按盖板轮廓切分，新增跟随盖板的内皮、开放内腔和密封条。原后挡玻璃、车顶、侧围、保险杠保持固定。铰链、归属及来源面数见 [节点映射](assets/vehicle-mapping.json)。补建为交互展示几何，未宣称厂商 CAD 尺寸或锁扣／气撑杆工程精度。

已通过：

- 四门和尾箱独立 0／50／100%，连续滑块、运动途中改向，其他门保持关闭。
- 每门三种开度 × 对应窗三种开度，四门合计 36 个组合，玻璃按门局部方向运动。
- 实际导出 GLB 的原门壳父子归属、门口无原外壳残留、尾箱关闭表面与打开内腔射线检查；见 [几何验证](assets/i4-geometry-verification.json)。
- 文字方向、半开、相对调节、对象追问和否定；共享车辆账本验证原子提交、版本、去重和不可用部件拒绝。
- 1920×1080 和 1366×768 的上述机械测试与模型热点、镜头拖动隔离，6 项场景测试通过（分批实际执行）。
- 52 项单元测试、类型检查、构建、ESLint、资产哈希检查及 15 张贴图打包检查通过。

发现并修复：初版热点的小球会被自身遮挡射线命中，导致 HTML 标签隐藏；移除多余球体后两种分辨率均实际点击通过。初版门回边跨组尖片已切分修复。尾箱开口使用从后方斜向内的射线验证，顶部垂直射线会先命中合法抬起的盖板，不将其误判为残留。

日志见 `docs/validation/i4/`；关键画面见 `docs/assets/i4-i6/I4-*`。原始几何审查见 [I4 原资产结构](assets/i4-original-audit.json)。现阶段未以 Mock 或预写转写替代新增真实语音；ASR／TTS 沿用用户本机阿里云配置，I5／I6 完成后合并复验。
