## 控制与语音框架

手动、文字和语音入口共用 Zod 命令 Schema、Zustand 车辆目标状态、校验器、去重执行器和帧动画驱动。实际显示开度另由几何驱动采样，目标不直接冒充完成。命令全量校验、按序计算、边界截断；相同请求不重复相对调整；新目标可中途改向。拖动镜头与点击选择有距离阈值，全开后的原开口仍可选择。

规则支持方向、明确全部、百分比、中文数字、一半、相对调节、边界、否定及完整子句检查。不明确对象先追问；当前对象和待澄清意图有两分钟有效期。未知子句不被悄悄丢弃；不调用 DeepSeek。

真实浏览器录音 API 已接入 WebM/Opus 与 AudioWorklet PCM WAV，含音量检测、自动静音结束、手动结束、取消、15 秒上限、无语音退出与 track 释放。状态包括录音、转写、解析、执行、合成和播报。服务端两种 ASR 音频协议和独立 TTS 适配已实现，但平台尚未确认。

ASR 结果具有请求 ID、录音开始时车辆版本和交互代次保护。新手动操作即使目标值未改变，也会作废旧语音结果。只有实际动画完成后才生成成功反馈；动作超时或被替代不会播报成功。新录音停止旧音频；播报失败保留动作和文字，可单独重播。
