# I5 灯光与外观阶段验证

2026-10-26，阶段 0.5.0；标签 `v0.5.0-i5-appearance`。I4 机构保留，新增真人语音待 I4–I6 完整后合并复验，不用 Mock 替代。

原 Paint1Mtl 克隆为 SU7_PAINT_BODY，明确 11 个漆面节点白名单，保留原金属度、粗糙度和贴图。运行时再克隆角色材质；轮胎、内饰、玻璃、灯罩等未进入白名单。七个预设与自定义颜色通过，真实渲染材质保护前后记录保存在浏览器报告附件。

新增前灯细 LED 轮廓和三个投射单元按原 Mesh70 灯罩几何最近表面拟合。近光／远光有不同投射单元、发光强度及实际 SpotLight 角度、照射距离和功率；“柔光展厅／夜间观察”只改变展示环境，不改变车辆灯光目标。“照射视角”可同时看到车辆和地面照明。固定视角关闭／近光／远光截图见 `docs/assets/i4-i6/I5-lamp-*`。没有使用泛光特效代替灯体。

前后琥珀灯条以 0.72 秒周期闪烁，左右／双闪是同一枚举，天然互斥。尾箱部分灯条随盖板移动，侧围段保持固定。仪表台与四门新增 5 段实际细管灯带，门上灯带以各自门轴为父节点；两个小范围局部灯仅补充座舱照明。原内饰红色装饰纹理保留，不将它们宣称为可控灯带。

座舱灯光入口锚定原 Mesh57 的左侧方向盘按钮，氛围灯入口锚定原中控屏。标签只在进入座舱附近显示，具有点击、悬停和选中反馈；无需重建整套按钮。门窗热点与控制面板继续有效。

验证通过：两种分辨率各 3 项外观测试，共 6 项；车漆保护、实际灯光功率与照射截图、转向闪烁和互斥、座舱灯带颜色／0–100% 亮度／相对调节、座舱两类热点实际点击。59 项单元测试通过，含复合亮度语句、否定、不完整句拒绝和灯光模式切换。原门窗和尾箱的几何归属／实际开口射线回归通过。
