# 下一轮起点

当前版本 0.3.1，已接通用户选择的阿里云北京地域千问 ASR（qwen3-asr-flash）和 CosyVoice（cosyvoice-v3-flash / longanyang）。I2 通过；真实接口探针、真实 API 合成音源浏览器动作、三次真人麦克风基础闭环均有记录，详见 [阿里云验收报告](ALIYUN_SPEECH_VALIDATION.md)。

当前演示：http://localhost:3000。配置已由用户保存在本机根 .env，密钥不进入 Git。历史只使用 Git 提交与标签，不复制工程；0.3.1 阶段标签为 v0.3.1-aliyun-speech。

本轮等待用户体验，不自动推进 I4。下一步先补 I3 真人复杂场景：

1. 明确试一次说完自动结束（本次真人诊断显示三次均为手动结束），以及实际噪声环境表现。
2. 真语音说“打开车窗”，确认追问，再回答“左后那个”；确认只调整一窗。
3. 播报时开始新录音，确认旧音频立即停止、麦克风不录入自身反馈；确认取消、重复与手动抢占后无旧动作。
4. 这些能力已有显式 Mock 浏览器回归，不将其冒充真实环境全覆盖。保留真实平台故障与设备差异的验证边界；需要时保存“调试记录→保存场景诊断 JSON”。

I3 体验满意并明确授权后再开始 I4 门／尾箱；现有 DOOR_*_ROOT 是窗口预留父节点。DeepSeek 留在 I7，不因 ASR 接入而提前启用。原内饰图集清晰度、实体按钮、门内侧、尾箱、雨刷仍按原计划增强。

API 字段、协议及真实探针命令见 [API_CONFIG.md](API_CONFIG.md)。npm run test:e2e 使用不读取 .env 的 3003 隔离测试服务，不消耗真实 Key；npm run speech:probe 是显式真实 API 测试，会产生少量调用。
