# 下一轮起点

本轮停止在 **I1 可观察 SU7**。先等待用户体验当前版本，不自动推进 I2。

得到继续授权后，以完整设计基线实施 **I2 四窗与统一领域**：

1. 先收集本轮视角、操作速度和座舱观察反馈，保留 I1 可运行版本。已收到“放大后有点糊”的反馈：内饰屏幕与按键共用 512×512 图集，细节增强候选见资产审查；先讨论增强优先级与需要操作的车内按键范围，不把贴图图标视作已实现交互。
2. 在 `assets/source/blender/su7-enhanced.blend` 中复核四窗候选：左前 Mesh46、右前 Mesh33、左后 Mesh39、右后 Mesh26。确认活动／固定玻璃边界、门内遮挡、跨组重复几何。
3. 建立语义节点与明确映射，校准局部升降方向和 0／50／100% 行程。不要直接把同材质全部玻璃当成活动窗。
4. 建立共享命令 Schema、状态、执行器、手动面板和文字规则；只实现 I2 的四窗闭环。动画应可中断，边界正确，拖动镜头不触发部件动作。
5. 保存同视角玻璃开口对比，验证 A03；回归当前 A01/A02、右键平移、自由移动、座舱、重置、错误恢复和两种分辨率。

模型尚无铰链、车门父子层级或尾箱分件保证；相关缺口继续按 I4–I6 完成。ASR／TTS 配置留到 I3，DeepSeek 到 I7。完整项目 R01–R19 的目标保持不变。
