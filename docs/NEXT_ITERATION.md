# 下一轮起点

当前停止于 **I2 四窗已完成 + I3 框架已完成，真实 API 接入延期**。遵循用户“暂不接入，先整体框架，最后告诉我填 API”的最新范围调整。等待用户体验，不自动推进 I4。

1. 用户准备好平台后，核对 ASR/TTS 文档、协议、实际模型和普通话音色；密钥只填根 `.env`。最少字段见 [API_CONFIG.md](API_CONFIG.md)。不假定文字兼容接口支持 Gemini 音频。
2. 重启服务，先做 gemini-3.8-flash 真实中文音频探针和独立 TTS 探针。协议不同时只扩展服务端适配，保持四窗执行器一致。保存去敏格式、模型、耗时与实际结果。
3. 真人说“左前车窗打开一半”，确认真实转写→规则→实际 50%→文字与普通话 API 音频。复验澄清、相对调节、手动抢占、旧响应、取消、新录音打断和故障恢复。通过后才勾选 I3 / A10。
4. 回归四窗和 I1；用户体验确认并授权后再开始 I4。DOOR_*_ROOT 只是窗口预留父节点，不是已完成车门机构。
