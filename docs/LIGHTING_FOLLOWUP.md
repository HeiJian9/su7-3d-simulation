# 中控灯带与全灯源散射修正 · 0.6.5

2026-10-27。基于 `25670ba` / `v0.6.4-cabin-lighting`，按用户新的截图和追加要求修复。演示 http://localhost:3000，阶段 Git 标签 `v0.6.5-lighting-followup`。I7 未启动，新部件真人语音仍待验。

## 根因与修改

上一版只检查灯片距内饰表面的距离，未验证是否沿着原生饰条；仪表台路径投影到了宽饰板和不连通面片，出现偏离、断续。撤回上一版“中控布局已贴合”的外观结论。此次改为直接读取 Mesh53 原中控横向饰条的边缘顶点，以及 Mesh59 中央托盘两侧饰条顶点，保留仪表开口与屏幕的实际遮挡。两段仪表台灯线、两段中央扶手灯线连续，无截断连接；四门上沿与把手灯保留，总计12处灯面。原车116个既有节点与0.6.3逐属性比较不变。

- 实际 GLB 检查：新四条灯片的全部顶点距指定原饰条中心路径不超过1.321毫米（含半幅宽和表面偏移），距真实表面约0.55毫米；四条灯片没有断面删除。原门窗、外灯、尾箱网格未修改。
- 前后转向散射来自实际六块发光面的几何中心：前两块、后四块。共用灯面当帧闪烁状态，亮时黄色，暗半周期与关闭时消失；左右独立，双闪同步。尾箱上的两块光源跟随真实尾箱变换。
- 氛围灯接入局部空气散射，随真实颜色、亮度、开关变化；0%与关闭后归零。八个局部照明光源增强至上一版的2.4倍，照亮门板、仪表台、中控和脚窝，四门灯光仍跟门运动。
- 前灯、转向灯与氛围灯统一受“丁达尔光束”和“空气散射”控制；关闭散射保留正常灯面与局部照明。散射采样96步，按场景深度裁切，车内部分限制在局部灯源附近。
- 修正间歇启用后处理时背景被额外色调映射而变暗的问题，直接渲染和体积渲染保留一致背景色。

这是可调的实时散射近似，使用场景相机深度与限定光体积；不代表真实空气颗粒物理测量，也未实现每个散射光源的完整体积阴影。灯光布局属于本项目展示增强，未声称复刻原厂完整氛围灯配置。
