# 0.7.4 · 前后排原生饰边照明

2026-10-29，基线 0.7.3。用户要求保持丰富的灯带覆盖，修正中控、前后排门板灯线与原车饰边不重合的问题。车窗青色选中轮廓经用户确认保留。

## 修改

在 10 个原车网格的材质上沿原网格边缘显示 27 条柔光路径，配合之前已验证的 4 段仪表台灯面，构成 31 条可见照明路径。覆盖前后四门的上沿、饰板、拉手与扬声器轮廓，中控托盘周边，以及中央扶手箱两侧、上缘与后端。16 个局部补光继续提供门板和前后脚窝照明。

旧的 21 个附加门板／中控灯面在运行时隐藏，其照明区域改由上述原车表面承担；不能把这一步当作删减这些区域。早期仅保留少数灯线的方案经用户指出氛围过弱后已撤回，最终补齐前后排层次。中间箱体额外保留上缘轮廓，避免只有较低的侧面路径而从上方看不到。

新的发光路径没有位移、没有重复管线或悬浮的覆盖面。左右公共饰边镜像对应，路径由原车顶点和实际三角形边生成；发光遮罩在原表面上按距离渐隐。保留原饰板纹理、反射及未发光部分。共享状态、面板、规则和 LLM 工具仍控制同一颜色、亮度和开关；车门上的照明随门移动。

实现：`apps/web/src/nativeAmbient.ts`、`data/native-ambient-paths.json`。路径可由只读脚本 `scripts/derive-native-ambient.py` 从当前 `.blend` 重新生成。该脚本只写路径数据，不保存或导出模型。正常资产导出继续使用 `npm run asset:export`。
