# 0.8.4 · 灯光外观面板统一

2026-10-30。根据用户截图，修正迎宾区与原控制面板在按钮、百分比、复选框和说明排版上的不一致。

- 流星雨和车门投影采用相同的控件行、开关按钮、按下状态及间距；移除原来未套样式的裸按钮。
- 七处亮度／散射设置共用 LightLevel：统一标签、数字与百分号、滑轨、焦点及禁用状态，保留原可访问名称和 0–100% 换算。
- 自动迎宾改为可键盘操作的滑动开关；说明精简为“锁定后解锁，播放约5秒。”，锁定按钮与提示对齐。
- 六个视角与遥控配对收进默认折叠的“视角与遥控”，展开后使用三列等宽按钮和完整宽度遥控入口。配对链接仍显示文字，不暴露令牌。
- 前灯、空气散射和前后排顶灯沿用统一亮度控件；顶灯开关各自与对应亮度分组，去除重复教学文案。

不修改模型、灯光渲染算法、22 项工具协议、ASR／TTS 或状态执行语义。0.8.3 的真实 API 八轮证据保留在 [原报告](WELCOME_CONTROLS.md)，本轮不重复调用云接口或新增真人通过声明。

验证见 [summary.json](validation/lighting-panel/summary.json)。两种窗口为 1920×1080 与 1366×768；实际渲染检查七处亮度绑定、Logo 门控、刷新与遥控、流星雨远端／中央效果及原氛围配色。新增 UI 检查覆盖键盘切换自动迎宾、键盘展开视角、配对入口、滑块边界及页面无横向溢出。截图复查修正了旧全局 i 圆点样式对开关轨道的影响。
