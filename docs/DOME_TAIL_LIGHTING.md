# 常亮后灯环与前后排顶灯 · 0.6.6

2026-10-27，基于 `697b314` / `v0.6.5-lighting-followup`。按用户标注将原后方外环保持启动状态下的亮红色，追加柔和散射；前后排中央增加向下照明的主灯，可通过模型热点、面板、文字和现有真实语音链路控制。演示 http://localhost:3000，Git阶段标签 `v0.6.6-dome-tail`。

## 实现与操作

- 后方外环使用 Mesh21／TRUNK_Mesh21 的714个原生外圈三角面，独立红色发光材质。内侧转向模块仍然仅在亮半周期发黄光，关灯时恢复原色。尾箱部分的红灯与原几何一同运动；未增加外置细管、未重新切分尾箱。
- 本演示按用户要求保持启动状态：红色行车灯环一直亮，关闭前灯／转向灯不会将它关闭。31个取自真实灯面的位置生成局部红色散射；“丁达尔光束”开关只关闭散射，红色灯面仍亮。空气散射滑块继续适用。
- 前排中央顶棚控制区、后排中央顶棚各一盏紧凑灯具，每盏含圆角灯壳与漫射罩。根据原顶棚射线命中点和法线安装，分别向下照明，带柔边、阴影和少量向下散射。属于本项目补建的展示灯具，不宣称原厂灯具尺寸复刻。
- 在“灯光外观→车内主灯”可分别开关；点击“前排顶灯视角／后排顶灯视角”定位后，可点击灯旁的模型热点标签。灯具初始关闭；拖动热点超过5像素不会开关。
- 支持“打开前排主灯”“关闭后排顶灯”“打开所有顶灯”“关闭所有顶灯”。明确选中单盏后，“关闭”沿用当前对象。仅说“打开顶灯”会追问前排／后排，可说“后排那个”或点击澄清选项。否定、过期请求、能力校验和重复请求去重沿用统一执行器。

顶灯已注册为独立 `cabinLight:front/rear` 能力，模型实际灯面和光源更新后才完成执行并播报。新增状态不会改动车窗、车门、雨刷或氛围灯。未接入DeepSeek，I7未启动。

## 实际验证

- 1920×1080与1366×768共 **14项浏览器回归通过**：后环默认红色常亮及转向独立、散射开关画面对照、尾箱移动、两盏主灯独立开关、热点／面板／规则状态一致、拖动防误触、向下照明画面对照、追问及否定；同时回归前照灯、转向闪烁、氛围灯亮度与随门运动。
- **77项单元测试通过**；类型检查、构建和Lint通过。门窗36种组合、尾箱几何、原灯面归属及内饰灯带贴合检查通过。
- 与0.6.5比较126个节点完全未改；两个后环节点仅改变指定面的材质，原位置／UV／法线／层级不变；只新增4个顶灯灯壳／灯罩节点。Blender内嵌贴图检查通过。
- 真实阿里云ASR/TTS **6条合成音源闭环通过**，包括前排开关、后排开启、全部关闭、模糊对象追问及“后排那个”回答。12个浏览器ASR/TTS请求全部成功，6次录音轨道均释放。[接口记录](validation/dome-tail/live-speech.json)。
- **输入音频为合成测试语音，并非真人麦克风；新增顶灯真人测试仍待用户方便时体验。** 不用这6条合成输入勾选真人验收。
