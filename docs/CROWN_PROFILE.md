# 0.7.6 · 仪表台上沿粗细与接头

2026-10-29。用户截图指出仪表台最前方灯带偏细、偏浅，与两侧连接处粗细不同。

原因是上沿仍使用旧的 2.4 mm 贴合灯面与 1.2 发光倍率，两侧已采用新的表面灯线和 1.8 倍率。上沿接近水平，正面观察的透视还会压缩可见宽度。

本轮沿原先已验证的 Mesh53 边缘路线生成 4.8 mm 浅圆弧扩散面（最高离面 1.4 mm），改善平面灯带在低机位下缩成细边的问题，并将上沿亮度倍率统一至 1.8。左右两段在接点共用同一截面和方向，不重复叠加同一段几何。弯折处横向分列，并对必要的跨面三角形启用自适应细分保护，逐点贴合实际表面，避免加宽后出现悬浮连接。实际 GLB 表面距离检查维持 1.5 mm 上限，没有放宽旧的贴合标准。

曾验证直接在上沿原生面上发光，但翻边遮挡造成断续，未采用。过宽的预览也被贴合检查拒绝；最终采用经过检查的 4.8 mm 拟合面。原有走线、仪表罩轮廓、前后排完整覆盖、33 条灯线和五个联动散射场继续使用。透视角度依然影响屏幕中的像素宽度，不承诺任何角度看起来完全等宽。

实现为运行时仅替换两个扩散面的几何与材质，退出时恢复并释放。`data/dashboard-profile.json` 是当前 Blender 原边缘的只读衍生数据，可用 `scripts/derive-dashboard-profile.py` 重新生成；脚本不保存／导出 `.blend`。基础 `.blend`、GLB、纹理文件和原生面板保持。正常模型导出仍用 `npm run asset:export`。

`validation/crown-profile/` 记录本轮结果，`assets/crown-profile/` 保存 40%／65% 夜间亮度和近景截图。单元检查直接读取运行 GLB，逐顶点及三角形中心验证贴合，并验证两个接头的全部截面顶点完全一致。浏览器验证两个分辨率、调光归零、散射、门板运动、底盘漏光及既有内衬；不增加真人或真实 API 通过声明。最终数量以 summary.json 为准。

演示：http://localhost:3000，帮助内显示 0.7.6。

最终结果：107 项单元／协议测试、22 项双分辨率浏览器回归通过；类型、规范、资产及生产构建通过。既有失败／未采用预览保留说明，不把自动截图标为真人验收。
