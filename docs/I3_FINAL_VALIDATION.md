## 本轮设计与修复

- 批量操作后的模糊“打开车窗”不再继承全部四窗；需要明确选择一窗或明确说全部。支持追问时明确回答“所有车窗”。
- 追问可用真人语音回答，新增取消入口；取消不会提交动作，撤销后不会因单独对象回答而继续执行旧意图。
- 播报中重录同步暂停实际播放器、释放 Blob URL，等待 180ms 再请求麦克风；缓冲中取消不再打开麦克风。
- 处理 WebM 停止异步间隔中的取消／重录，阻止旧音频回调混入新录音或留下未结算等待。
- 补齐逐轮转写、追问、完成开度、实际暂停位置和麦克风释放记录。
- 真人试用暴露“打开右后方的车窗／关闭右后方车窗”未被规则识别；已补方向规范化，经单元、浏览器和真实 API 复测通过。未知复杂表达仍留给 I7 DeepSeek 兜底，本轮未接入。

## 真实 API 复测

[真实 API／合成音源报告](validation/i3-final/live-advanced.json) 已通过。测试不替代真人设备：

1. 先执行“全部关闭”，再输入真实 API 合成的“打开车窗”。真实千问转写后先追问，四窗仍全部 0%。
2. 在真实提问播报中开始新录音，输入“左后那个”。实际左后窗到 100%，其他窗不变。
3. 在执行反馈播报中再次重录，输入“右前车窗打开一半”。最终 fl=0、fr=0.5、rl=1、rr=0。
4. 实际 HTMLAudio 两次暂停，之后才开始采集；最终复测间隔 180／181ms。额外先手动打开右后窗到 100%，再用真实音频“关闭右后方车窗”验证实际关闭至 0%。第五次录音取消，未上传；五个合成输入 stream 的 track 均已停止。
5. 四次 ASR 和四次 TTS 接口均 HTTP 200，无 Mock 网络响应。保留 [最终阶段诊断](validation/scene-diagnostics-2026-10-26T13-03-03-902Z.json)、[追问截图](assets/i3-final/live-clarification.png)、[最终姿态截图](assets/i3-final/live-interruption-result.png)。

## 自动化与真人结果

类型、构建、Lint 通过，45 项单元测试通过，见 [日志](validation/i3-final/unit.log)。双分辨率完整浏览器回归 55 通过、1 计划跳过（1366 重复长时用例），包含 I1 两分钟相机、I2 四窗及 I3 故障／取消／WebM 晚回调。见 [完整原始报告](validation/i3-final/playwright-full.json)。新增方向措辞和明确全体回答的 2 项定向测试通过，最后的布局定向复测另存 [报告](validation/i3-final/playwright-results.json)。按用例／项目合并结果见同目录 summary.json。

最终合并为 **57 通过、1 计划跳过、0 遗留失败**。追问状态下的 1366 窗口面板曾裁剪右后按钮约 7px，首次布局定向检查如实失败，已扩展可用高度；最后两分辨率追问／取消复测均通过，四窗按钮完全可见。初次 [布局报告](validation/i3-final/playwright-layout-first.json) 与最终报告均保留，未伪装成一次全绿运行。

用户完成本机体验后回复“ok，你自己来验证下是否可以了”。已核对 [真人诊断](validation/scene-diagnostics-2026-10-26T12-59-36-316Z.json)：两次录音由 silence-end 自动结束，之后才上传；“打开车窗”正确触发追问，未提交动作；用户随后明确改说“打开所有车窗”，才执行四窗 100%。实际播报到 1137ms 时被新录音暂停，182ms 后才请求新输入，后续转写为用户的新话语，未混入旧播报内容。六次释放记录均为 all ended:true。数据摘要见 [验收证据](validation/i3-final/acceptance-evidence.json)。

用户没有逐字复现“左后那个→右前半开”的指定顺序，该精确补全序列由真实 API／合成音源测试覆盖；不把合成音源标为真人。真人额外说出的“右后方”措辞在第一次体验时被安全拒绝、没有误动作，现已修复并定向复测。真人自动结束／追问发起／实际播报打断、真实 API 精确补全／几何和受控错误恢复组合满足当前 I3 四窗范围验收。未承诺所有房间噪声或所有自然语言均可识别。

错误场景通过明确的故障注入验证，包含权限拒绝、无设备、无配置、空录音、格式、认证、限流、超时、断网、无效 JSON 与 TTS 失败重播；不伪装成真实平台曾经发生这些故障。API Key 只在本机 .env，普通测试不读取它，不向前端发送。
