# 原接缝前备箱与宽角顶灯 · 0.6.7

2026-10-27，基于 `d1608ab` / `v0.6.6-dome-tail`。按用户标注的前盖原分割线增加前备箱，同时按补充要求将前后排主灯调为宽角柔和散射。演示 http://localhost:3000；Git阶段标签 `v0.6.7-native-frunk`。I7未启动。

## 模型和动作

- 原前盖来自 Paint7 的完整原生面片岛；主盖边界为 **82个原始顶点**，不使用人工包围盒或新切线。1230个原面归入可动盖板，其余原车身保持固定，Mi徽标 Mesh65及底座一同运动。
- 与0.6.6逐三角面对照：Paint7的5936面和Mesh65的208面完整保留，位置与UV最大误差均为0；法线重编码最大误差约0.0005。其余 **130个既有节点完全不变**。
- 后沿铰链开启，支持0–100%连续开度、关闭／半开／全开、相对调节和动画中断改向。前后备箱是独立状态。
- 补建盖板内侧、退入原盖板轮廓内的密封边和储物腔、两处铰链连接件。关闭时沿原外壳接缝；开盖后可直接看到储物腔。顶视2875条射线及四个视角共7917条车体命中射线未发现补件越过关闭外表面。半开和全开均验证了从前方通向储物腔的实际开口。
- 点原盖板上的“前备箱”热点即可开关；热点随盖板移动，开启后也可点击关闭。拖动超过5像素不切换。面板位于“门与尾箱”，提供滑块、三档按钮及“前备箱视角”。

新增内腔和铰链为本项目的必要展示增强，未声称原厂容积、锁止或气撑杆机构的工程复刻。

## 控制与语音

手动、文字、真实ASR结果共用 `frunk:front:openness` 状态和执行器；动作到位才播报完成。

示例：“打开前备箱”“前备箱打开一半”“再关一点”“关闭前备箱”；也支持“前舱盖”“前机盖”“引擎盖”“机舱盖”。否定、能力校验、边界、重复请求去重、过期响应保护沿用原统一领域。

真实ASR曾把合成音“前备箱打开一半”转为“前辈想打开一半”。保留实际转写证据，规则层为这类限定的前备箱控制短语增加词形纠正；没有改写ASR接口原返回，也没有预写转写文本。[实际原转写](validation/frunk/asr-probe.json)。未知完整表达仍不执行，DeepSeek保持在I7。

## 顶灯补充修正

前后排主灯的实际SpotLight全角约 **143°**、柔边0.9，以向下为主向两侧铺光；各增加1.2强度、1.4米范围的局部补光。体积散射改为宽角衰减分布，避免细直束的表现。两盏灯继续独立开关，关闭时主光、补光、灯面发光和各自散射均停止。

浏览器分别测量了驾驶位和副驾侧画面：只开前排主灯时，两处实际像素区域均变亮；后排灯仍保持关闭。角度与补光的检查值取自真实渲染对象。散射仍为实时近似，非测量级光学仿真。
