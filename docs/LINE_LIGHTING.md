# 0.7.5 · 前门上沿与灯线联动柔光

2026-10-29，基线 0.7.4 / `8f76808`。用户指出前门木纹饰板缺少与后门对应的上沿灯线，且更新后的灯带仍配合旧点状补光／散射，部分区域过暗。

## 实际修改

- 左右前门增加完整的饰板上沿路径，使用原 Mesh49／Mesh36 可见内侧边缘。首次外侧边缘预览有遮挡断点，改用内侧原生连续边后通过几何与近景复查。四门饰板均保留上下层轮廓。现在为 29 条原生路径加 4 段原仪表台灯面，共 33 条。
- 原生门板、中控和扶手箱周围增加按灯线距离渐隐的材质柔光。柔光保留原材质颜色／纹理，避免大面积平涂；黑色内饰仍保持明暗层次。此项为局部表面补光近似，并非完整的多次反弹全局光照。
- 16 个局部光源继续使用。门板补光根据当前上沿与拉手路径重新定位，向内侧移出，降低点源峰值、扩大柔光范围；中间箱体补光升至可见区域。四个脚窝阴影灯与底板遮光保持。
- 空气散射改为依据全部 33 条当前发光路径生成五个局部光场：座舱主体与四门各一个。四门光场按真实门铰链变换采样，随门转动；颜色、亮度、开关均读取当前统一状态，空气强度继续由既有散射控件／工具控制。
- 光场使用小型 R8 三维纹理，合计 245,760 字节，避免逐像素逐段遍历所有灯线。每帧继续采用真实场景深度终止射线；光场不覆盖外门皮、车顶和底板以下。空气效果属于局部实时散射近似，不声称完整介质多重散射或逐光源体积阴影。
- 退出／卸载释放三维光场纹理；原生表面照明恢复原材质和几何。`.blend`、GLB、纹理文件保持，车窗选中轮廓保持。

## 验证

独立证据在 `validation/line-lighting/`，截图在 `assets/line-lighting/`。最终数量与实际结果以 `summary.json` 为准。

几何检查读取实际运行 GLB，验证两侧上沿均为原生边、左右镜像对应、所有发光路径存在，原顶点与索引不变。光场检查验证五个分组包含全部当前路径，底板以下与门外侧采样为空。

浏览器检查真实图像在 0／35／80% 空气强度下的变化，验证光场随右前门转动、其余场不被误改、亮度归零／关闭后散射归零；同时回归原生前灯、转向灯、尾灯、顶灯、脚窝遮光、前后备箱内衬及两个分辨率布局。自动截图不作为新增真人确认；ASR、LLM、CosyVoice 与唤醒配置沿用上一版。

演示：http://localhost:3000，帮助内版本 0.7.5。“暮光紫”配色＋夜间观察可直接检查；“空气散射强度”调整空气效果，不替代灯光亮度。日间与夜间均保持原来的场景观察方式。

最终结果：106 项单元／协议测试、26 项双分辨率浏览器回归全部通过；类型、规范、资产、生产构建通过。图像比较显示 35% 与 80% 空气强度均有实际亮度变化，且 80% 高于 35%；具体像素统计、门板矩阵和分组见 summary.json。
