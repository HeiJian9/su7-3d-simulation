# 指定 SU7：I4–I6 资产修改记录

整理日期 2026-10-27。唯一工作工程 `assets/source/blender/su7-enhanced.blend`；历史由 Git 保存。原始只读下载包未修改。

| 资产 | 实际来源与加工 |
|---|---|
| 四门 | Paint4／2／3／1 外壳及原各门门板、把手、镜体；Paint6 跨门回边沿 B 柱切开。实际门根节点在前侧铰链处旋转，最大 65°，玻璃仍为门根下的独立升降子节点。 |
| 尾箱 | 在 Paint5 及 10 个相关原灯条、标志／饰件网格上切分盖板；旋转轴设在原后挡玻璃后缘附近，最大 68°。补盖板内皮、空腔及密封条；车顶、后挡、侧围、保险杠固定。 |
| 漆面 | 克隆原 Paint1Mtl 为 SU7_PAINT_BODY，限定 11 个原漆面节点；保留原粗糙度、金属度和图像。 |
| 灯体 | 原 Mesh70 透明灯罩保留，灯罩曲面下补细 LED 和投射单元；前后琥珀段按左右拆分，尾箱段随盖板移动。运行时发光、投射光和闪烁独立于原共享材质。 |
| 灯带 | 仪表台及原四门饰条旁补 5 段细管，门上灯带归对应门；两个有限范围的局部灯补照，不使用泛光特效。 |
| 雨刷 | 从原 Mesh24 拆出主驾 256 面、副驾 306 面的实际组件，原 UV／材质和拓扑保留；删除原停放位置的重复面。以原 Mesh69 前挡确定转轴方向，62° 扫掠；8 个曲面贴合修正形态由实际根节点旋转配合插值。原副驾机构缩短并重新贴合，消除与主驾轴附近的交叉。运行 scale 均为 1；独立 WIPER_GRAPHITE 石墨灰材质增强深色背景下的可见性，不影响原共享材质。 |
| 座舱入口 | 精确锚定原 Mesh57 左／右方向盘按钮和中控屏附近的标签热点。没有重建整套按键，亦未把页面面板当作模型内入口。 |
